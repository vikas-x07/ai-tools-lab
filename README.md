# AI Tools Lab
## Project Description
AI Tools Lab is a small Python project created to practise Git/GitHub workflows and AI-assisted
development. It contains a sorting algorithm implementation and a set of general-purpose utility
functions, developed and documented with the help of AI coding assistants.
## Features
- Bubble Sort implementation (sorting.py)
- Utility functions: palindrome check, word count, Celsius-to-Fahrenheit conversion (utils.py)
- Simple entry-point script (hello.py)
## Installation Instructions
```bash
git clone <repository-url>
cd ai-tools-lab
python --version # Python 3.8 or above recommended
```
## Usage Examples
```python
from sorting import bubble_sort
print(bubble_sort([5, 2, 9, 1])) # [1, 2, 5, 9]
from utils import is_palindrome, count_words, celsius_to_fahrenheit
print(is_palindrome("madam")) # True
print(count_words("Python is easy")) # 3
print(celsius_to_fahrenheit(25)) # 77.0
```
